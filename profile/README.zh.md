Oleafly 是一款免费、开源的科研写作桌面应用。你用 LaTeX、Typst 或 Markdown 写作，编译好的 PDF 就在源文件旁边，论文其余的工作也在同一个窗口里完成：查找和引用文献、绘制图表、提交前检查，需要帮忙时还可以把某一节交给 AI 助手或编程智能体。合作者可以通过你们小组自己运行的服务器与你实时协作编辑。每个项目都仍是你电脑上的普通文件夹，所以你的工作永远不依赖我们。
