Oleaflyは、研究論文を書くための無料でオープンソースのデスクトップアプリです。LaTeX、Typst、Markdownのソースの隣にコンパイル済みのPDFを置いて書けます。文献を探して引用する、図を描く、投稿前にチェックする、必要なときにはAIアシスタントやコーディングエージェントに節を任せる。論文まわりの作業はすべて同じウィンドウで完結します。共著者とは、グループで運用するサーバーを通じてリアルタイムに編集できます。どのプロジェクトもコンピューター上の普通のフォルダーのままなので、あなたの研究が私たちに依存することはありません。
