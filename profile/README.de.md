Oleafly ist eine kostenlose Open-Source-Desktop-App für wissenschaftliches Schreiben. Du schreibst LaTeX, Typst oder Markdown mit dem kompilierten PDF neben dem Quelltext, und der Rest der Arbeit an deinem Paper passiert im selben Fenster: Quellen finden und zitieren, Abbildungen zeichnen, eine Einreichung prüfen und einen Abschnitt an einen KI-Assistenten oder einen Coding-Agenten übergeben, wenn du Hilfe willst. Deine Mitautor:innen bearbeiten das Projekt in Echtzeit mit dir, über einen Server, den deine Arbeitsgruppe betreibt. Jedes Projekt bleibt ein ganz normaler Ordner auf deinem Computer, deine Arbeit hängt also nie von uns ab.
