Oleafly est une application de bureau gratuite et open source pour la rédaction scientifique. Vous écrivez en LaTeX, Typst ou Markdown avec le PDF compilé à côté du source, et le reste du travail sur l'article se fait dans la même fenêtre : trouver et citer des sources, dessiner des figures, vérifier une soumission, et confier une section à un assistant IA ou à un agent de code quand vous voulez de l'aide. Vos coauteurs peuvent modifier le projet avec vous en temps réel, via un serveur géré par votre équipe. Chaque projet reste un dossier ordinaire sur votre ordinateur : votre travail ne dépend jamais de nous.
