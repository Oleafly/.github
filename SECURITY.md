# Security policy

## Reporting a vulnerability

If you find a security issue in any Oleafly project, please report it
responsibly and do not open a public issue.

The best way to report is to use GitHub's private vulnerability reporting on
the relevant repository. Open the Security tab and choose
"Report a vulnerability". The report goes to the maintainers privately.

If you cannot use that, send a private message to the maintainers through
GitHub.

## Supported versions

The latest release of each project is supported. Reports against unreleased
development builds are still welcome and appreciated.

## What to include

A clear description of the issue, the steps to reproduce it, the project and
platform affected, and the impact. If you have a proposed fix, please include
that as well.
